# MySQL Data Cleaning Project

# Project Overview
This project focuses on cleaning and preparing a real-world layoffs dataset using MySQL.
The objective was to transform raw and inconsistent data into a clean, structured dataset that can be used for further analysis and reporting.

# Tools & Technologies
* MySQL
* SQL
* MySQL Workbench

# Data Cleaning Steps
The project involved:
* Removing duplicate records
* Handling NULL and blank values
* Standardizing inconsistent data
* Cleaning text fields
* Converting and formatting date values
* Identifying and removing unnecessary records
* Creating staging tables to preserve the original dataset
* Validating the cleaned dataset
